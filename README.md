# RecipeManager

## Overview
Recipe Manager is a Windows Presentation Foundation (WPF) application designed to help users manage recipes. Users can add, display, scale, reset, and filter recipes. The application also includes a warning for recipes exceeding 300 calories and allows users to tick off steps as they complete them.

## Features
Add recipes with ingredients and steps
Display all recipes or filter by ingredient, food group, and calories
Scale recipes by a factor of 0.5, 2, or 3
Reset ingredient quantities to original values
Clear all recipe data
Display detailed recipe information
Warn when a recipe exceeds 300 calories with a red warning message
Tick off steps as they are completed
## System Requirements
Windows operating system
.NET Framework 4.7.2 or later
## Installation
Download the Recipe Manager executable from the provided link.
Run the installer and follow the on-screen instructions.
Launch the application from the Start Menu or desktop shortcut.
## Usage
### Main Window
Add Recipe: Opens the Add Recipe window.
Display Recipes: Lists all recipes in alphabetical order.
Scale Recipe: Scales the quantities of ingredients for the selected recipe.
Reset Quantities: Resets ingredient quantities to their original values for the selected recipe.
Clear Data: Removes all recipes from the application.
Exit: Closes the application.
Filter Options: Filters recipes based on ingredient name, food group, and maximum calories.
### Add Recipe Window
Recipe Name: Enter the name of the recipe.
Add Ingredient: Opens the Add Ingredient window.
Ingredients List: Displays ingredients added to the recipe.
Add Step: Adds a step to the recipe.
Steps List: Displays steps added to the recipe.
Save: Saves the recipe.
